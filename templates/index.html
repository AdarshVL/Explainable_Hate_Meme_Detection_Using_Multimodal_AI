API Documentation

POST /api/predict

Analyze a single meme image

curl -X POST http://localhost:5000/api/predict \

-F "image=@meme.jpg" \

-F "text=meme caption" \

-F "explain=true"

Response: JSON with prediction, confidence, explanations

GET /api/history

Get all previous predictions

curl http://localhost:5000/api/history

Returns: Array of past predictions with timestamps

GET /api/stats

Get statistics and model metrics

curl http://localhost:5000/api/stats

Returns: Stats including accuracy, total predictions, class distribution

Python Example:

import requests

with open('meme.jpg', 'rb') as f:

  files = {'image': f, 'text': 'caption', 'explain': 'true'}

  r = requests.post('http://localhost:5000/api/predict', files=files)

  result = r.json()

  print(result['prediction']['class_name'])
